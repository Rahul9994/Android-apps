# Android Apps

This folder holds all of the user's Android Studio projects. Create every new Android project here as its own subfolder (`E:\ANDROID APPS\<AppName>`), never anywhere else.

## Environment
- Android Studio: `C:\Program Files\Android\Android Studio`
- Android SDK: `%LOCALAPPDATA%\Android\Sdk`
- `adb` is not on PATH — call it as `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`
- Emulator: `%LOCALAPPDATA%\Android\Sdk\emulator\emulator.exe`
